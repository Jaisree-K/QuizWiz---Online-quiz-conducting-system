QuizWiz System

Simple Online Quiz Conducting System • Project Leap / Java + DBMS

Problem Statement:

Faculty traditionally conduct short quizzes on paper, which requires manual correction, leads to late feedback for students, and consumes valuable class time. QuizWiz automates quiz creation, question bank administration, strict timer enforcement, immediate scoring, and student-wise analytics.

Architecture & Stack:

  • Backend: Java 17, Spring Boot (Spring Web, Spring Data JPA, Hibernate, Bean Validation)
  • Database: MySQL (Relational tables: students, quizzes, questions, attempts, attempt_answers)
  • Frontend: Single responsive HTML5 / Vanilla CSS / JavaScript interface directly served via Spring Boot
  • Business Logic Enforced: Duplicate attempt rejection, server-side timer validation, auto-submission, selective scoring for answered questions.
